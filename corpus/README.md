# 기존 글 원본 넣는 곳

여기 들어온 글이 **톤앤매너의 정답지**가 됩니다. 여기가 부실하면 결과물도 부실합니다.

## 몇 개나 필요한가

| 개수 | 결과 |
|---|---|
| 1~2편 | 패턴이 아니라 우연을 학습함. 비추천 |
| **5편** | 최소 기준. 말투·구조가 잡힘 |
| **8~10편** | 권장. 주제별 변주까지 학습 가능 |

## 어떤 글을 골라야 하나

**조회수 높은 글이 아니라, 검색으로 유입되는 글**을 주세요.

1순위 — 상위노출 확인된 글 (키워드 검색 시 상단 노출)
2순위 — 검색 유입 비중이 높은 글
3순위 — 사장님이 "이렇게 써지면 좋겠다" 싶은 글

## 넣는 방법 (둘 중 아무거나 / 섞어도 됨)

### 방법 1 — URL만 알려주기
채팅에 URL을 붙여주시면 Claude가 읽어서 이 폴더에 저장합니다.
네이버 블로그는 iframe 구조라 간혹 실패하는데, 그때는 모바일 주소로 재시도합니다.

### 방법 2 — 텍스트 붙여넣기
채팅에 본문을 그대로 붙여주세요. 확실합니다.
**제목도 함께** 주세요. 제목 패턴이 상위노출의 절반입니다.

## 함께 주시면 좋은 것 (선택)

각 글마다 한 줄이면 충분합니다.

```
글1 - "성대결절 목소리" 키워드 3위, 월 유입 400
글2 - 유입 많음, 순위는 모름
글3 - 톤이 제일 마음에 드는 글
```

이게 있으면 "무엇이 먹혔는지"를 알고 그 구조를 복제합니다. 없어도 진행은 가능합니다.

## 파일 규칙 (자동 저장 시)

```
corpus/001__성대결절-목소리.md
corpus/002__발성연습-방법.md
```

각 파일 상단에 메타데이터가 붙습니다.

```markdown
---
title: 원본 제목
url: https://blog.naver.com/...
keyword: 성대결절 목소리
rank: 3
chars: 2140
collected: 2026-09-05
---
```
