# 사장님이 고쳐 발행한 원고

내 초안과 실제 발행본의 차이가 **가장 정확한 피드백**입니다.
무엇을 고치셨는지 기계적으로 뽑아내 다음 글에 반영합니다.

## 왜 파일로 받아야 하나

이 작업 환경은 **네이버 도메인 전체가 조직 네트워크 정책으로 차단**되어 있습니다.

```
blog.naver.com / m.blog.naver.com   CONNECT 403 (policy denial)
search.naver.com / openapi.naver.com 연결 불가
```

URL을 주셔도 제가 열어볼 수 없습니다. 본문을 붙여넣어 주셔야 합니다.
(관리자가 이 환경의 네이버 접근을 허용하면 자동화할 수 있습니다. 아래 참고)

## 넣는 방법

발행하신 글의 **제목과 본문 전체**를 채팅에 붙여주시면 아래 형식으로 저장합니다.

```
revisions/2026-09-05__1.md      ← drafts/2026-09-05/1.md 의 발행본
```

파일 상단 메타데이터

```markdown
---
draft: drafts/2026-09-05/1.md
url: https://blog.naver.com/voicedr/224403800429
title: (실제 발행 제목)
published: 2026-09-05
---
```

## 비교

```bash
python3 scripts/compare_revision.py drafts/2026-09-05/1.md revisions/2026-09-05__1.md
```

출력되는 것

- 분량 변화 (글자수 · 블록 · 문장 수 · 평균 문장 길이)
- 어미 분포 변화 (~습니다 / ~죠 / ~겁니다 / ~요)
- 브랜드 문구를 늘리셨는지 줄이셨는지
- **빼신 문장과 넣으신 문장 목록**

여기서 반복되는 패턴을 `brand/tone-and-manner.md` H섹션에 규칙으로 옮깁니다.
한두 편으로는 우연이고, **3편 이상 쌓이면 패턴**입니다.
