## Claude가 확장하는 방식

씨앗 1개 → 대략 5~8개로 늘립니다.

```
씨앗: 발성연습
 ├─ 방법형   : 발성연습 방법, 집에서 발성연습, 발성연습 순서
 ├─ 대상형   : 직장인 발성연습, 초보 발성연습
 ├─ 문제형   : 발성연습 해도 안 될 때, 발성연습 목 아픔
 ├─ 비교형   : 복식호흡 vs 흉식호흡
 └─ 롱테일   : 목소리 작을 때 발성연습
```

확장 결과는 `queue.tsv` 에 쌓이고, 사장님이 승인/삭제할 수 있습니다.
