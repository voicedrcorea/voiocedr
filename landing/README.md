# 닥터브레스 랜딩 페이지

블로그 자동화와는 별개로, `drbreath.liveklass.com` 상담 유입용
랜딩 페이지(DR.Breath)의 원본과 작업 도구를 보관한다.

## 파일

| 파일 | 설명 |
|---|---|
| `drbreath-landing.html` | 원본. 사진은 `images/` 를 참조한다. 여기를 고친다 |
| `drbreath-landing.inlined.html` | 배포본. 사진까지 전부 품은 단일 파일 (약 2.0 MB) |
| `section-program-flow.html` | "닥터브레스 프로그램은?" 섹션만 떼어낸 조각 |
| `inline_images.py` | `images/` 의 사진을 HTML 본문에 base64 로 박아 넣는다 |
| `images/` | 웹용으로 줄인 사진 6장 |

고칠 때는 `drbreath-landing.html` 을 고치고 아래를 한 번 돌린다.
`drbreath-landing.inlined.html` 이 다시 만들어진다.

```
python3 landing/inline_images.py landing/drbreath-landing.html
```

## 프로그램 소개 섹션

후기 섹션(`#review`) 아래, 가격 섹션(`#pricing`) 위에 들어간다.
세로 타임라인 3단계다.

1. 상담 신청 후 검사지 작성 + 호흡 영상 셀카 촬영 → 담당 트레이너 전달
2. 담당 트레이너가 진단 후 프로그램 배치
3. 2주 간격(스케줄에 따라 12~17일) 재진단 후 프로그램 재배치

기존 페이지 스타일을 그대로 따른다.
브랜드 컬러 번호 배지, `accent-500` + `shadow-cta` CTA, `rounded-2xl` 카드,
`break-keep`, 섹션 상단 영문 라벨(`PROCESS`).

위 후기 섹션이 `bg-slate-50`, 아래 가격 섹션이 `bg-white` 라서
그 사이는 연한 브랜드 그라데이션으로 두 흰 섹션이 붙어 보이지 않게 했다.

## 사진

| 파일 | 내용 | 크기 |
|---|---|---|
| `images/selfie-1.jpg` | 셀카 (전신, 세로) | 675×1200 |
| `images/selfie-2.jpg` | 셀카2 (검사지 작성, 가로) | 1200×675 |
| `images/program-1.jpg` | 영상1 경추 움직임 호흡 | 1302×696 |
| `images/program-2.jpg` | 영상2 천천히 호흡을 빼겠습니다 | 1307×695 |
| `images/program-3.jpg` | 영상3 앉은 자세, 다섯 | 1309×699 |
| `images/program-4.jpg` | 영상4 누운 자세, 옆구리 | 1298×691 |

셀카 2장은 PNG 원본이 각 1.7 MB 였다. 그대로 넣으니 페이지가 6.2 MB 로
불어서, 긴 변 1200px JPEG 로 줄여 각 70~85 KB 로 만들었다. 페이지는 2.0 MB 다.
원본 PNG 는 저장소에 두지 않는다. 다시 줄일 일이 있으면 사장님 원본을 받는다.

셀카 2장은 세로(9:16)와 가로(16:9)로 비율이 엇갈린다. 같은 크기 박스에
넣으면 가로 사진이 가운데 얇은 띠처럼 떠서 둘이 따로 논다. 그래서
데스크톱에서는 **높이만 맞추고 폭은 사진 비율대로** 두었다. 잘리는 곳이 없다.
모바일에서는 세로로 쌓고 각자 제 비율을 쓴다.

사진 순서는 본문 문장을 따른다. "검사지를 작성하고, 셀카를 촬영해" 이므로
검사지 사진이 먼저다.

## 확인하지 못한 것

이 작업 환경은 `cdn.tailwindcss.com` 이 조직 네트워크 정책으로 차단되어 있다
(CONNECT 403). 그래서 페이지 전체를 브라우저로 렌더해 본 적이 없다.
사진이 박스에 앉는 모양만 Tailwind 클래스의 배치값을 직접 CSS 로 재현해
데스크톱·태블릿·모바일 세 폭에서 확인했다. 나머지는 태그 균형과 클래스
계산만 맞춰 둔 상태다. **발행 전에 사람이 직접 열어서 봐야 한다.**
