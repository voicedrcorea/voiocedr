### 줄바꿈 (이 블로그의 시그니처)

> **지표 읽는 법 주의.** 위 표의 '문단 48개'는 corpus를 저장할 때
> 빈 줄을 정규화한 상태에서 센 값입니다. 실제 발행 글은 이보다 훨씬 잘게
> 쪼개져 있습니다. 생성 원고는 발행 형태 그대로 쓰므로 **블록 70~95개**가
> 정상이며, 이 둘을 같은 숫자로 비교하면 안 됩니다.

네이버 모바일 가독성에 최적화된 극단적 줄바꿈이 이 블로그의 정체성입니다.

- **1~2문장마다** 줄바꿈
- **의미 단락 사이에 빈 줄 3~6개**
- 한 화면에 텍스트가 꽉 차지 않게 — 여백이 많음
- 문장이 길면 어절 단위로 끊어 다음 줄로 내림

이 규칙이 깨지면 다른 블로그 글처럼 보입니다. **최우선 유지 항목.**

## C. 구조 골격 (4편 모두 동일 — 브랜드 공식)

```
 1. 훅        잘못된 통념·조언을 따옴표로 3~5개 나열
              또는 독자가 겪는 증상 나열
 2. 반전      "사실 여기엔 큰 함정이 있습니다"
              "하지만 안타깝게도 ~ 좋아지지 않습니다"
 3. 재정의    그건 [연기/스피치/톤]의 문제가 아니라 '발성'의 문제다
 4. 비유 ①   기본 체력 없이 경기 뛰기 / 발목 아픈데 달리기
 5. 브랜드    "17년 (차·경력) 발성 전문 트레이닝 센터 보이스 닥터입니다"
              ※ 도입부가 아니라 본문 30~40% 지점에 등장
 6. 영상      비포&애프터 + 면책 괄호(전문 직업군 비공개)
 7. 요약      [접기/펴기] 3~5문장, 메인 키워드 포함
 8. 차별화    방법·노하우가 아니라 '소리를 잘 낼 수 있는 몸 상태'
 9. 해부학    횡격막 / 갈비뼈 / 척추 / 골반 / 복횡근 / 골반기저근 / 자세 정렬
10. 1:1 당위  사람마다 원인이 달라서 커리큘럼·그룹수업으로는 안 됨
11. (선택)    실제 회원 사례 문단  ※ 004에만 있음
12. CTA       회원제 운영 / 당일 방문 불가 / 사전 연락 후 예약
```

## D. 브랜드 도그마 (매 글에 반드시 관통해야 하는 메시지)

1. **"방법이 아니라 상태"** — 최상위 메시지. 모든 글의 결론
2. **'소리를 잘 낼 수 있는 몸 상태'** — 브랜드 고유 문구. 표현 그대로 사용
3. **17년** — 경력 숫자는 항상 등장
4. **오직 1:1** — 커리큘럼·그룹 부정
5. **각자 원인이 다르다** — 1:1의 논리적 근거
6. **돌고 돌아 마지막에 오는 곳** — 타 학원 실패 후 방문 서사

## E. 제목 전략 (네이버 스마트블록 대응)

### 현재 로직에서 확인된 원칙

VIEW 탭이 사라지고 **스마트블록**이 검색 결과를 나누면서, 제목의 역할이
"키워드를 넣는 것"에서 **"어떤 검색 의도의 블록에 들어갈지 선언하는 것"** 으로 바뀌었습니다.

| 원칙 | 내용 |
|---|---|
| 키워드 위치 | 메인 키워드를 **제목 맨 앞**에. 앞쪽일수록 가중치가 높다 |
| 키워드 횟수 | 제목에 **1회만**. 반복하면 스터핑으로 감점 |
| 본문 연동 | 제목 키워드를 첫 문단 1회, 본문 중 3~5회 자연스럽게 |
| 길이 | **20~30자**. 모바일 검색결과에서 뒤가 잘린다 |
| 의도 선명도 | 한 제목이 한 의도만 겨냥. 여러 의도를 섞으면 어느 블록에도 못 들어간다 |
| 금지 | 낚시성 과장, 특수문자·이모지, 키워드 나열식 제목 |

### 매 글 제목 후보 6개 — 의도 유형별

한 키워드도 검색 의도가 여러 갈래라 스마트블록이 여러 개 생깁니다.
그래서 **유형이 다른 6개**를 뽑아 사장님이 고르게 합니다. 같은 유형 2개는 만들지 않습니다.

| # | 유형 | 겨냥하는 블록 | 형태 |
|---|---|---|---|
| 1 | **원인형** | 문제 진단 | `[키워드]` + `아무리 ~해도` + `좋아지지 않는 이유` |
| 2 | **방법형** | 정보·해결 | `[키워드]` + `~보다 먼저 해야 할 것` / `~하는 순서` |
| 3 | **대상형** | 롱테일 | `[키워드]` + `[구체적 대상]이` + `~할 때` |
| 4 | **증상형** | 상황 검색 | `[키워드]` + `[구체적 상황 묘사]` + `이유` |
| 5 | **질문형** | Q&A 블록 | `[키워드]` + `~일까요` / `~해도 될까요` |
| 6 | **비교형** | 의사결정 | `[키워드]` + `A와 B 중 먼저인 것` |

**1번 원인형은 브랜드 시그니처입니다.** corpus 4편이 모두 이 형태이고 실제로 상위노출 중이라
항상 1순위에 둡니다. 나머지 5개는 아직 잡지 못한 블록을 노리는 확장용입니다.
