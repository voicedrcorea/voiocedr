# 가드레일 (원고 생성 시 강제 적용)

> corpus 4편을 실제로 검토한 뒤 **브랜드가 이미 쓰고 있는 표현에 맞춰 조정**한 버전입니다.
> 톤을 해치지 않는 선에서 리스크만 걷어냅니다.

---

## 1. 유사문서 방지 — 이번 프로젝트 최대 리스크 ⚠️

### 왜 최우선인가

corpus 4편은 **구조 골격이 거의 동일**합니다.
(훅 → 반전 → 재정의 → 브랜드 인사 → 비포애프터 → 접기펴기 → 차별화 → 해부학 → 1:1 → CTA)

지금은 상위노출이 잘 되고 있지만, **같은 골격으로 하루 3편씩 90편을 찍어내면**
네이버가 자기 글끼리 유사문서로 판정할 위험이 급격히 올라갑니다.

### 강제 규칙

| # | 규칙 | 판정 |
|---|---|---|
| 1 | 기존 글 및 당일 생성한 다른 2편과 **연속 15자 이상 동일 문장 없음** | 자동 검사 |
| 2 | 도입부(훅) 첫 3문장은 기존 어떤 글과도 소재가 다를 것 | 자동 검사 |
| 3 | **골격 12단계 중 3~4단계는 순서를 바꾸거나 생략** | 생성 시 강제 |
| 4 | 비유는 매 글 **새로 창작**. `tone-and-manner.md` F섹션 목록 재사용 금지 | 생성 시 강제 |
| 5 | 부정 대상(복식호흡·볼펜·풍선 등)은 글마다 **다른 조합**으로 3개 이하 | 생성 시 강제 |
| 6 | 같은 날 3편의 타깃 독자가 서로 다를 것 (예: 일반인 / 지망생 / 현직) | 생성 시 강제 |
| 7 | 소제목·요약문 문구가 기존 글과 겹치지 않을 것 | 자동 검사 |

**예외 — 일부러 반복해야 하는 것**
브랜드 도그마 문구(`소리를 잘 낼 수 있는 상태`, `17년`, `오직 1:1`)는
브랜드 정체성이므로 **반복이 정상**입니다. 유사도 계산에서 제외합니다.

## 2. 의료 표현 (비의료 사업자)

보이스닥터는 **비의료 트레이닝 센터**입니다. 다만 브랜드가 이미 쓰고 있는
`진단` `교정` 은 트레이닝 맥락의 고유 용어이므로 **그대로 유지**합니다.

### 유지 (브랜드 기존 용법 — 바꾸지 않음)

- `진단` — "왜 힘이 들어가는지를 진단하고" (상태 파악의 의미)
- `교정` — "목소리 교정", "발성 교정 전문센터"
- `발성기능` `호흡근` `횡격막` 등 해부학 용어 (설명 목적)

### 금지 (자동 치환)

| 금지 | 대체 |
|---|---|
| 치료 / 치료법 / 치료해드립니다 | 훈련 / 개선 / 트레이닝 |
| 완치 / 완치됩니다 | (삭제) |
| 처방 | 맞춤 훈련 설계 |
| 부작용 없는 / 안전한 | (삭제) |
| 환자 | 회원 / 수강생 |
| 질환을 낫게 한다 / 고친다 | 발성 습관을 다시 잡는다 |

### 질환명 취급 규칙

`성대결절` `성대폴립` `연축성 발성장애` `근긴장성 발성장애` 등은
corpus에서 **제3자의 과거 경험을 서술할 때만** 등장합니다. 이 용법을 유지합니다.

- ✅ "성대결절로 몇 년 동안 고생하셨지만" (회원의 과거 상태 서술)
- ✅ "심하게는 연축성, 근긴장성 발성장애와 같은 목소리 떨림이 생기시는 경우도" (경고 맥락)
- ❌ "보이스닥터가 성대결절을 해결합니다" (비의료가 질환 해결 주체가 됨)
- ❌ "성대결절 치료" 를 제목·키워드로 사용

> 질환명이 한 글에 **3회 이상** 등장하면 웹페이지에 ⚠️ 표시하고 사람 검수를 요청합니다.

## 3. 표시·광고법 (과장광고)

### corpus에서 발견된 리스크 표현 — 사장님 판단 필요

| 표현 | 출처 | 리스크 | 제안 |
|---|---|---|---|
| **"국내 유일 호흡근 트레이닝이 가능한 곳"** | 004 | **배타성 주장은 실증 자료 제출 의무**가 생깁니다 (표시광고법 제5조). 객관적 근거가 없으면 부당광고가 될 수 있습니다 | `국내에서 보기 드문` / `호흡근 트레이닝을 전문으로 다루는` 등으로 완화 권장 |
| **"목소리 문제의 90%"** | 002 | 출처 없는 통계 수치 | `대부분` / `상당수` 로 대체 권장 |
| "문제를 정확히 진단하고" | 003 | 낮음 (트레이닝 맥락) | 유지 가능 |

> **이건 제가 임의로 바꾸지 않았습니다.** 사장님이 근거를 갖고 계실 수도 있고,
> 기존 글은 이미 발행되어 성과를 내고 있기 때문입니다.
> 아래 D항의 질문에 답해주시면 신규 글 생성 규칙에 반영합니다.

### 신규 글에 항상 금지

- `100%` `무조건` `반드시 효과` `최고` `1위` `단 한 곳` (근거 없을 때)
- 실측 자료 없는 수치·통계 (`수강생 98% 만족` 등)
- 타 업체 실명 비방
- **창작 후기 절대 금지** — 실제 사례가 없으면 사례 문단 자체를 생략

- [ ] 수치·통계·비율 인용
