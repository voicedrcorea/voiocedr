# 필자 프로파일 — "이 사람이라면"

> **이 문서가 최상위 기준입니다.** 수치나 최신 발행본보다 우선합니다.
>
> 목적은 매번 새 글에 맞춰 규칙을 바꾸는 것이 아니라,
> **한 사람의 일관된 문체를 재현**하는 것입니다.
> 새 발행본은 이 프로파일을 **검증**하는 데 쓰지, 갈아엎는 데 쓰지 않습니다.
>
> 표본: corpus 4편(2024~2026 상위노출 글) + 발행본 3편. 총 7편.

---

## 1. 이 사람이 믿는 것 (모든 글의 척추)

**"방법이 아니라 상태다."**

7편 전부가 이 한 문장의 변주입니다. 글의 주제가 무엇이든 결론은 같습니다.
새 글을 쓸 때 이 축에서 벗어나면 다른 사람의 글이 됩니다.

파생 신념 — 순서대로 자주 등장합니다.

1. **원인과 결과가 뒤집혀 있다** — "목이 약한 게 아니라, 목이 안 해도 될 일까지 하고 있다"
2. **개인차가 크다** → 그래서 1:1이어야 한다
3. **방법·노하우는 그 사람 몸에서 나온 답이다** → 나에게 맞을 리 없다
4. **몸은 소리를 포기하지 않는다** → 그래서 엉뚱한 근육을 끌어다 쓴다
5. **다른 곳을 돌다 마지막에 오는 곳**

## 2. 이 사람이 **쓰지 않는** 것

| 안 씀 | 근거 | 대신 |
|---|---|---|
| `안녕하세요` | 발행본 3/3에서 삭제 | 바로 `17년 차 발성 전문 트레이닝 센터 보이스 닥터입니다` |
| `~죠` 남발 | 발행본에서 계속 지움 (편당 0~1회) | `~입니다` `~겁니다` |
| 시간·기간 한정 (`오전/오후`, `몇 년째`, `하루 여덟 시간`) | 발행본 3/3에서 제거 | 일반화된 서술 |
| 추측·완충 표현 (`~일 수도 있습니다`, `~하시면 좋을 것 같습니다`) | 7편 전부 단정형 | `~입니다` 로 단정 |
| 병원을 서사 주체로 (`병원에서 쉬라고 해서`) | 발행본에서 삭제 | 주체 없이 `쉬라는 이야기를 듣거나` |
| 이모지·특수문자 | 7편 전부 0개 | 작은따옴표 강조 |
| 창작 후기·가짜 사례 | — | 실제 없으면 문단째 생략 |
| 근거 없는 수치 | — | (기존 글의 `90%`는 사장님 확정으로 예외) |
| `치료` `완치` `처방` `환자` | 비의료 사업자 | `훈련` `개선` `회원` |

> **외래어는 씁니다.** `퀄리티` `콘텐츠` `피지컬` `레벨테스트` 실제 사용.
> 외래어를 피하려고 어색한 한자어로 바꾸지 않습니다.

## 3. 이 사람이 **강조하는** 것

| 강조 | 실제 표현 |
|---|---|
| 독자를 탓하지 않음 | "여러분의 목이 약한 게 아닙니다" / "성실하지 않아서가 아닙니다" |
| 몸의 메커니즘 | 횡격막 · 복횡근 · 골반기저근 · 연구개 · 갈비뼈 · 전방 경사 |
| 브랜드 이름 | `보이스 닥터` — 발행본 3/3에서 노출을 **늘리심** |
| 1:1 당위 | `오직 1:1로만` — 개인차 설명 직후에 배치 |
| 17년 | 매 글 2회 내외 |
| 결과가 아니라 조건 | "버틸 수 있는 힘을 기르는 것" |

## 4. 문장 습관

- **단정형 종결.** `~입니다` `~겁니다`. 추측형을 거의 안 씀
- **반문으로 전환.** `그럼 무엇이 문제일까요?` `어떻게 될까요?` — 편당 2회 이상
- **명사형 단독 문장으로 끊기.** `근본적인 원인.` `다음은 '자세' 문제입니다.`
- **작은따옴표로 개념 강조.** `'소리를 잘 낼 수 있는 몸 상태'`
- **큰따옴표로 남의 말 인용.** `"목소리 좀 크게 해봐."`
- **구어체 강조를 섞음.** `말도 안 되는 겁니다.` `허리를 똑바로 펴! 로 해결될 문제가 아닌`
- **비유는 문답으로 전개.** 상황 제시 → `그렇다면 어떻게 해결해야 할까요?` → 한 줄 결론

## 5. 글을 끝내는 방식

```
(본문 마지막) 결론 한 줄 — 원리 + 해결
              예: "유튜버 목소리는 결국 오래 버틸 수 있는 호흡근의 문제입니다.
                   해결 방법은 장비를 바꾸는 것이 아니라 그 호흡근을 운영하는 몸을 만드는 것입니다."

보이스 닥터는 회원제로 운영되어 당일 방문 상담은 어렵습니다.
아래로 먼저 문의하신 뒤 일정 조율 부탁드립니다.
```

앞머리(`저희 센터는` / `센터는` / `보이스 닥터는`)와
(`아래로` / `아래 안내에 따라`)는 변주합니다. **뒷부분은 고정입니다.**

## 6. 분량은 1,600~1,900자다 (2026-09-16 두 번째 정정)

> **이 항목에서 두 번 틀렸습니다.**
>
> 처음에는 하한을 정해두고 맞추려 문단을 덧붙였고, 사장님이 그 덧붙인
> 부분을 잘라내셨습니다. 그래서 **하한을 아예 없앴습니다.**
> 4편 초안을 1,505자로 짧게 냈더니 이번엔 **138자를 더하셨습니다.**

발행본 네 편의 실측값입니다.

```
1,901   1,825   1,628   1,643
```

**하한은 실재합니다.** 제가 두 가지를 혼동했습니다.
잘라내신 것은 글이 길어서가 아니라 **덧붙인 문장이 필요 없어서**였습니다.

- 목표 범위 **1,600~1,900자**. 필요한 단계를 다 쓰면 자연히 여기에 들어옵니다
- **1,500자 아래 = 빠진 단계가 있다는 신호.** 채우라는 뜻이 아니라
  무엇이 빠졌는지 찾으라는 뜻입니다. 4편에서 빠져 있던 것은
  `여러분` 호칭, `운영` 개념, 전문 트레이너 문장, 잘못된 지시 나열이었습니다
- **2,000자 초과 = 필요 없는 문장을 덧붙였다는 신호**
- 짧아서 걱정될 때는 문장을 늘리지 말고 **H18~H21이 들어갔는지**부터 봅니다

같은 이유로 블록 수도 목표치가 아닙니다. 아래 7번 줄바꿈 규칙을
지키면 자연히 그 범위에 들어옵니다.

## 7. 줄바꿈 양식 (네이버 스마트에디터 모바일 기준)

이 블로그의 정체성입니다. **가장 눈에 띄는 차이이므로 가장 정확히 지킵니다.**

### 규칙

| 항목 | 값 |
|---|---|
| 한 줄 최대 | **24자** (모바일에서 오른쪽에 2~3칸 여백이 남는 지점) |
| 권장 길이 | 16~22자 |
| 끊는 위치 | **어절 경계.** 단어를 쪼개지 않음 |
| 문장이 길면 | 한 줄에 밀어넣지 말고 **의미 단위로 먼저 아래줄로** |
| 문단 사이 | 빈 줄. 발행 시 3~6줄로 벌림 |

### 실제 예 (발행본에서)

```
강의를 하시는 분들이라면 아마 매일 겪고
계실 겁니다.

그러다 결국 쉰 목소리가 유지되거나
갈라지는 목소리가 되는 등의 여러 문제를
겪으십니다.

그래서 마이크도 바꿔보고 발성 영상을 찾아보며
복식호흡이나 립버블 같은 것도 따라 해봅니다.
```

한 문장이 두세 줄로 나뉘고, 각 줄이 24자를 넘지 않습니다.

### 적용

```bash
python3 scripts/wrap_lines.py drafts/YYYY-MM-DD/*.md
```

원고를 다 쓴 뒤 반드시 이 스크립트를 돌립니다.

## 8. 키워드는 지어내지 않는다

큐의 모든 키워드는 **월간 검색량 수치를 갖는다.** 근거 없이 만들어 넣지 않는다.
기준은 `keywords/POLICY.md` 에 있다.

- 실제 검색어 형태 그대로 쓴다. 명사구로 비틀지 않는다
- 업계 용어(`호흡근` `연구개` `복횡근`)는 본문에서 설명할 말이지 제목 키워드가 아니다
- 검색량만이 아니라 전환 의도를 함께 본다

> 2026-09-16 이전의 큐 30개는 전부 근거 없이 만들어진 것이었다.
> `호흡근 훈련이란`, `발성 좋아지는 신호` 같은 것이 그대로 발행됐다.

## 9. 이 프로파일을 고치는 기준

새 발행본이 들어오면 **이 프로파일과 어긋나는지**를 봅니다.

| 상황 | 조치 |
|---|---|
| 프로파일과 일치 | 아무것도 바꾸지 않는다. 검증된 것이다 |
| 한 편만 어긋남 | 기록만 한다. 그 글의 사정일 수 있다 |
| **세 편 연속 어긋남** | 그때 프로파일을 고친다 |

**최신 발행본을 따라 매번 기준을 옮기지 않습니다.**
그렇게 하면 기준점이 사라지고 이동 평균만 남습니다.
