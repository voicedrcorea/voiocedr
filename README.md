# 보이스닥터 블로그 자동 생성 시스템

네이버 블로그 원고를 **월·화에 각 2편씩(주 4편)** 자동 생성하는 저장소입니다.

## 발행 주기

| 요일 | 월 | 화 | 수 | 목 | 금 | 토 | 일 |
|---|---|---|---|---|---|---|---|
| 원고 | **2편** | **2편** | — | — | — | — | — |

## 발행일 흐름

```
월·화 06:57 KST  Routine 자동 실행 (클라우드, PC 안 켜도 됨)
   │
   ├─ brand/ 에서 톤앤매너·가드레일 로드
   ├─ corpus/ 에서 기존 상위노출 글 구조 참조
   ├─ keywords/queue.tsv 에서 오늘 키워드 3개 pick (used.tsv 제외)
   ├─ 원고 3편 생성 (2000자 내외)
   ├─ 자체 검수 (유사도 / 금칙어 / 글자수 / 키워드 밀도)
   ├─ drafts/YYYY-MM-DD/ 에 커밋 + used.tsv 갱신
   └─ 웹페이지(아티팩트) 갱신 → 알림으로 링크 도착

아침에 링크 열기 → [제목 복사] [본문 복사] → 네이버 붙여넣기 → 예약발행
```

## 폴더 설명

| 경로 | 용도 | 누가 채우나 |
|---|---|---|
| `brand/profile.md` | 브랜드 기본정보, CTA 소재 | **사장님** |
| `brand/tone-and-manner.md` | 말투·구성 규칙 (원본 분석 결과) | Claude가 자동 추출 |
| `brand/guardrails.md` | 금칙어, 법적 리스크 표현 | Claude + 사장님 검토 |
| `corpus/` | 기존 상위노출 글 원본 | **사장님** (URL 또는 텍스트) |
| `keywords/seed.md` | 핵심 키워드 (씨앗) | **사장님** |
| `keywords/queue.tsv` | 확장된 키워드 큐 | Claude가 자동 확장 |
| `keywords/used.tsv` | 소진 이력 (중복 방지의 근거) | 시스템이 자동 기록 |
| `drafts/` | 날짜별 완성 원고 | 시스템이 자동 생성 |
| `delivery/` | 아티팩트 URL 등 전달 설정 | 시스템 |
