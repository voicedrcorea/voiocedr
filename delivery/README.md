# 전달 설정

## 방식
매일 생성된 원고 3편을 **하나의 고정 웹페이지**에 갱신 발행합니다.
URL이 매일 바뀌지 않으므로 북마크 한 번만 해두시면 됩니다.

## 페이지에 들어가는 것
- 오늘의 원고 3편 (제목 후보 3개씩 / 본문 / 태그 / 이미지 삽입 지시)
- 각 항목마다 **복사 버튼** — 누르고 네이버 스마트에디터에 붙여넣기
- 검수 경고 표시 (⚠️ 수치 인용 / 질환명 다수 / 후기 문단 / 가격 언급)
- 최근 7일치 원고 히스토리

## artifact-url.txt
발행된 고정 URL이 여기 저장됩니다. Routine이 매일 이 파일을 읽어
같은 주소에 덮어씁니다. **이 파일을 지우면 URL이 새로 생깁니다.**
