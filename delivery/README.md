# 전달 설정

## 방식
매일 생성된 원고 3편을 **하나의 고정 웹페이지**에 갱신 발행합니다.
URL이 매일 바뀌지 않으므로 북마크 한 번만 해두시면 됩니다.

## 페이지에 들어가는 것
- 오늘의 원고 3편 (제목 후보 3개씩 / 본문 / 태그 / 이미지 삽입 지시)
- 각 항목마다 **복사 버튼** — 누르고 네이버 스마트에디터에 붙여넣기
- 검수 경고 표시 (⚠️ 수치 인용 / 질환명 다수 / 후기 문단 / 가격 언급)
- 상단 날짜 칩으로 지난 원고를 골라 볼 수 있음 (검수 신호가 있는 날은 점 표시)

## 날짜 선택

`scripts/build_page.py` 는 `drafts/` 아래 **모든 날짜**를 페이지에 담습니다.
열릴 때는 가장 최근 날짜가 선택되고, 상단 칩을 눌러 지난 날짜로 이동합니다.

```
python3 scripts/build_page.py             # 최신 날짜가 열린 상태
python3 scripts/build_page.py 2026-09-05  # 그 날짜가 열린 상태
```

과거 원고 폴더를 지우면 페이지에서도 사라집니다.
